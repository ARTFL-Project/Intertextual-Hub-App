# intertextual-hub — the application dependency set, for uv-managed CPython 3.11.
#
# This is the FULL resolved set, not only the direct pins. spaCy's helper libraries
# (catalogue, cymem, murmurhash, preshed, srsly, wasabi, thinc, blis) are tightly coupled and
# version skew between them is exactly where this stack breaks. Pin what was tested.
#
# WHY 3.11 AND NOT HIGHER. spaCy 2.3.9 is the ceiling: it and its compiled helpers ship wheels
# up to cp311, never cp312, and spaCy 2 cannot be traded for 3 - the 2020 French model and the
# lemmas the tf-idf index was built from are spaCy 2's. spaCy 2 also needs numpy < 2.
#
# WHAT MUST NOT MOVE, and the pin that holds it. Each was verified against the Python 3.8
# production container on 2026-09-23; raising one of these means re-running that check.
#   spacy 2.3.9, thinc 7.4.6   lemmatiser output byte-identical (T1's 105-token French sample),
#                              with fr_core_news_lg 2.3.0 (Dockerfile).
#   scikit-learn 1.4.2         the Hub's 2020 TfidfVectorizer pickle: transform output and idf_
#                              byte-identical. 1.5 changed how TfidfTransformer stores idf and
#                              the pickle then raises NotFittedError. 1.4.2 is the last before.
#   pystemmer 2.2.0.3          French stems identical over 5,000 TopoLogic words. 3.x's newer
#                              Snowball stems differently, which would change federated search.
#   gensim 4.3.3               loads the 2020 word2vec models through load_vectors() in
#                              api/words/explore_words.py: vocabulary, order and vectors
#                              identical; similarity scores within 5e-7 (float32), so words
#                              tied to that precision can swap places. Accepted.
#   annoy 1.17.0               the on-disk format of tf_idf_index.annoy.
#   numpy 1.26.4               < 2 for spaCy 2 and gensim 4.3; the last 1.x.
#   lxml 6.1.0                 PhiloLogic's rendering. 4.5.2 silently truncated passages.
#   mmh3 5.3.0                 text_preprocessing hashes tokens with it: values identical to 2.5.1.
#
# THINGS THIS FILE CANNOT EXPRESS, all handled in the Dockerfile:
#   1. fr_core_news_lg==2.3.0 comes from a spacy-models GitHub release, not PyPI.
#   2. spacy/data/fr must be symlinked to the model package. text_preprocessing maps
#      "french" -> "fr" and calls spacy.load("fr"), which is a spaCy 2.x shortcut and not
#      a package name. Without the link the Hub app dies at import with OSError E050.
#   3. text_preprocessing is an ARTFL package and is not on PyPI at all.
#   4. philologic 4.6 is not on PyPI either: its C core and Python package are built from
#      ARTFL-Project/PhiloLogic4 at the pinned commits.
#   5. topologic is installed --no-deps, without topic_num_evaluator. Its install_requires
#      names nltk, matplotlib and pandas, all for model building, which this container never
#      does. Everything it imports when serving is pinned here.
#
# DROPPED from the 2020 VM's freeze - nothing served imports them: nltk, pyjwt, matplotlib,
#   pillow, cycler, kiwisolver, pyparsing, pandas, python-dateutil, pytz, regex, chardet,
#   aiofiles (only Starlette < 1 used it), and python-jose with ecdsa, rsa and pyasn1.
#   setuptools stays only because spaCy 2 declares it; at 84 it has no pkg_resources, and
#   nothing served needs one (spaCy, click and thinc import it lazily, on paths never taken).
#
# The security reasoning behind individual pins (h11, joblib, gunicorn, requests/urllib3, lxml,
# and the web framework's path here) is in this file's git history for 2026-09-23. Worth
# keeping in view:
#   fastapi 0.141.1, starlette 1.7.0, pydantic 2.13.5   every Starlette HIGH is fixed only in
#                              Starlette >= 1.3.1, which needs FastAPI >= 0.133, which needs
#                              pydantic 2. Neither app defines a pydantic model, so v2 is
#                              visible only in the wording of 422 error bodies. Missing static
#                              files now 404 as JSON {"detail":"Not Found"} instead of text.
#   pyjwt 2.15.0               replaces python-jose, whose ecdsa dependency carried a HIGH with
#                              no fix. Same encode/decode signatures; tokens are standard HS256
#                              JWTs either way, so sessions issued before the switch stay valid.
#   gunicorn 23.0.0            its lifecycle (start, HUP, respawn, heartbeat, TERM) was tested
#                              with uvicorn 0.12.1's worker. uvicorn is 0.12.1 still.
#   uvloop 0.21.0              0.22 no longer creates an event loop implicitly, and uvicorn
#                              0.12.1's worker relies on that: every worker dies at start with
#                              "There is no current event loop". Moving uvloop means moving uvicorn.
